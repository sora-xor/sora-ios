# Sr25519SafeValidator third-party licenses

This directory is bundled with SORA Wallet and contains the exact upstream
license files for every package pinned by the validator's `Cargo.lock`, plus
the exact Rust 1.46 nightly runtime license and copyright notices. The locked
package index and explanatory notices are maintained in
`VendorPackages/shared-features-spm/Rust/Sr25519SafeValidator/THIRD_PARTY_NOTICES.md`.

The framework uses MIT for dependencies offered under MIT or Apache-2.0 and
MIT for byteorder's MIT or Unlicense choice. BSD and CC0 dependencies retain
their complete upstream texts in this directory.
